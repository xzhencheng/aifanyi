## M0：质量基线与模型 PoC

- [ ] DATA-01：整理脱敏业务样本，建立六方向标注规范与文档级数据划分。
- [ ] MODEL-01：验证专用翻译模型与通用模型适配器，执行 E0–E4 对照。
- [ ] 单独评估初译错误、审校召回/误报、修复纠错及新增错误。
- [ ] DOC-01：提前验证 Word/Excel 片段映射、行内样式和共享字符串往返。
- [ ] 记录候选模型、资源使用、未知项和试点质量门槛。

完成条件：取得基线和选型证据，不能仅以模型能运行作为质量验证通过。

## M1：准确性内核

- [ ] CORE-01：源文、片段、候选、修订、问题、裁决和快照模型。
- [ ] CORE-02：上下文构建、概念消歧、有效规则及可信 TM 资格检查。
- [ ] CORE-03：初译、确定性检查、原文审校、有限修复、人工处理和记录。
- [ ] API-01：同步文本协议、幂等、错误及超时后的任务查询。
- [ ] UI-01：原译对照、证据定位、修订和人工裁决。
- [ ] 验证关键语义难例，失败和缺失审校不能伪成功。

完成条件：真实模型可运行，原意、信息完整和专业概念问题可追踪；保持基线对照。

## M2：持久任务与知识治理

- [ ] JOB-01：异步批量、队列、租约、恢复、取消、状态与版本并发控制。
- [ ] GOV-01：术语/TM/规则/解释材料、发布快照、四级反馈、影响分析和回滚。
- [ ] AUTH-01：身份、项目隔离、客户端和 Secret 配置。
- [ ] INT-01：Outbox、登记端点、HMAC、退避、事件去重与人工重发。
- [ ] 验证重复派发、模型响应未知、暂停恢复、回调失败及跨项目负例。

完成条件：任务和通知状态独立，知识发布可审计，恢复不重复产生正式结果。

## M3：Office 文件与工作台

- [ ] DOC-02：Word 受支持纯文本、样式标记、原位回填和结构检查。
- [ ] DOC-03：Excel 范围、类型保护、共享字符串隔离和引用验证。
- [ ] UI-02：文件范围确认、未支持对象报告、任务/审核/模型配置页面。
- [ ] AGENT-01：对话查询、带依据解释、局部重译和反馈草稿工具。
- [ ] 验证安全解析、实际阅读器打开和版式风险提示。

完成条件：全部目标片段及结构检查通过才提供正式结果，未支持对象原样保留且显式报告。

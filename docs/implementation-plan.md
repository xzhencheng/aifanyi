## 1. 文本翻译最小闭环

目标：用户输入文本后能获得真实模型译文、质量结果和可追溯的任务记录。

- [ ] 定义请求/结果结构、语种和错误码，输出 OpenAPI 契约。
- [ ] 实现模型网关与可配置的模型适配器；模型不可用时明确报错，不以模拟译文冒充成功。
- [ ] 实现基础规则加载与已发布术语匹配。
- [ ] 实现型号、数字、占位符保护及译后校验。
- [ ] 实现 `POST /v1/translations` 与任务审计持久化。
- [ ] 实现文本翻译工作台及错误、加载、复核状态。
- [ ] 完成身份鉴别及项目/结果访问隔离。

交付条件：中英日典型文本闭环可运行，成功与失败路径可追踪；提供真实配置接入说明和人工验证步骤。

- [ ] 创建持久化任务状态模型和 Worker 执行机制。

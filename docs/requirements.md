## 1. 建设目标与范围

建立独立翻译 Agent，首期覆盖中文、英文、日文双向互译。统一治理术语、翻译记忆和规则，让经审核的修正能够服务后续任务，并向业务系统提供同步、异步和结果查询能力。

优先业务场景为维保资料、产品手册、技术通知；模型通过网关接入，避免业务流程绑定单一供应方。

### 1.1 范围边界

| 对象 | 一期处理范围 | 保持原样或排除的内容 |
| --- | --- | --- |
| 文本 | 短文本、长文本、批量文本 | 高风险内容保留人工终审 |
| Word `.docx` | 正文、标题、列表、表格、页眉、页脚中的普通文本 | 图片、图表、SmartArt、形状文本、域/公式、嵌入对象、批注、控件等非支持对象 |
| Excel `.xlsx` | 值类型为字符串的普通单元格，可选择工作表或区域 | 公式、数字、日期、图片、图表、形状、批注、控件等非支持对象 |
| 其他文件 | 不支持 | `.doc`、`.xls`、PDF、PPT/PPTX、图片、扫描件、含宏格式 |

纯文本支持边界必须在上传确认和结果报告中明确展示。未支持对象应保留原样，并报告数量；未知对象不得静默丢弃。

保留原有结构和样式，不等同于保证翻译前后分页完全一致。语言长度变化可能造成换页或单元格显示溢出，默认不缩小字号或修改列宽，异常内容提示人工检查。

## 2. 角色与权限

| 角色 | 主要职责 |
| --- | --- |
| 普通用户 | 发起翻译、查看授权结果、提交反馈、管理个人偏好 |
| 项目翻译管理员 | 审核和发布项目知识，管理项目范围内的翻译质量 |
| 企业术语/内容负责人 | 审核和发布企业知识、锁定关键项、执行版本回滚 |
| 系统管理员 | 管理调用系统、模型配置、回调端点、运维与数据保留策略 |
| API 调用系统 | 在授权范围内创建任务、查询状态、下载结果、接收事件 |

权限控制覆盖项目、任务、知识、文件和回调端点。任务查询及文件下载同样执行授权校验。

## 3. 翻译 Agent

处理流程：原文与上下文构建 → 固定知识和模型配置版本 → 专业概念消歧及知识装配 → 模型初译或有效记忆复用 → 确定性检查及完整原文对照审校 → 定向修复或人工审阅 → 文档一致性与交付检查。

默认准确性优先策略覆盖全部目标片段。专用翻译模型和通用初译模型采用相同业务样本对照，审校模型独立配置；不能把使用双模型直接视为准确性提升的证明。

- 短文本同步返回译文及质量元数据。
- 长文本、批量文本和文件采用持久化异步任务，创建成功返回 `202`、任务标识及状态查询地址。
- 支持追问、译法解释、局部重译和按本次修正重新翻译；对话能力后续通过独立接口提供。
- 网关记录模型、提示模板、耗时、用量、失败原因等信息；支持模型替换及可配置路由。
- 模型降级仍受数据分级和部署边界约束，不自动将敏感材料转交未授权供应方。

## 4. 三类知识与版本

| 知识类别 | 内容 | 使用方式 |
| --- | --- | --- |
| 术语库 | 标准/禁用译法、领域、上下文、作用范围、大小写、禁译、优先级、锁定标记 | 每次匹配原文，只向模型装配命中术语，译后再次校验 |
| 翻译记忆库 | 经人工确认的双语或多语句段、来源、上下文、审核状态与有效范围 | 批量检索；有效完全匹配可复用，相似匹配仅作参考 |
| 翻译规则库 | 风格、型号/代码/公式/占位符保护、格式要求、质量阈值、提示模板 | 按语种、项目及场景加载；未配置时使用企业默认规则 |

适用知识先按身份、范围、发布状态、语言和语境筛选。强制规则与企业锁定项优先；仅在允许覆盖的键上使用“本次要求 → 当前用户个人项 → 项目项 → 企业默认”，同级冲突进入待确认。企业锁定项不可被项目或个人覆盖。

翻译记忆是候选译文，必须符合当前术语、规则、上下文和权限才可复用。领域解释材料辅助概念消歧，不能向译文擅自添加原文没有的信息。

每个任务记录规则、术语、翻译记忆、模型和提示模板版本。文件任务在创建时固定知识快照，重试和续跑继续使用同一快照。任务执行期间的知识发布不影响已固定快照。

术语更新时定位受影响的翻译记忆并标记待复核，不直接对句段进行批量字符串替换。未重新确认的受影响记忆不得继续作为可信完全匹配直接复用。

## 5. 反馈治理

| 作用范围 | 生效规则 | 是否进入正式公共知识 |
| --- | --- | --- |
| 仅本次 | 用于当前任务重译，保留审计记录 | 否 |
| 个人 | 对本人后续任务生效，不得覆盖企业锁定项 | 否，存入个人层 |
| 项目 | 经项目管理员审核、发布后生效 | 项目库 |
| 企业 | 经企业负责人审核、影响分析、版本发布后生效 | 企业库 |

专业词修正形成术语建议；整句修正形成记忆建议；普遍性风格或格式调整形成规则草稿；仅适用当前上下文的调整不进入共享库。AI 分类仅为建议，不替代审核授权。

流程包含草稿、提交、审核、发布、撤回和回滚；记录操作人、原因、时间、来源任务及新旧版本。

## 6. Office 文件处理

文件流程：上传与鉴权 → 类型和安全检查 → OOXML 解析 → 提取支持文本 → 批量知识检索 → 分段翻译与质检 → 原位回填 → 结构校验 → 下载与事件通知。

### 6.1 Word

- 复制原文件；按段落聚合文字片段并记录原始 OOXML 节点、样式及文本映射。
- 为片段分配稳定 `segment_id`，将必要的行内样式边界编码为受保护标记。
- 译文必须通过片段 ID 和标记完整性校验后才能回填；异常内容重试或转人工，不盲目写入。
- 复用原有字符和段落样式，保留编号、书签、链接、分页、图片及文档结构。
- 输出重新解析，核对段落、表格、图片、书签、样式等结构，并检查空译文及文件损坏。

### 6.2 Excel

- 仅支持范围内的字符串单元格生成翻译片段，记录工作表、坐标、原值和样式标识。
- 公式及其缓存、数字和日期不送入模型，不修改合并区域、行列尺寸、样式、链接、隐藏状态和数据验证。
- 回填保持字符串类型，模型生成以 `=` 等字符开头的译文也不得意外成为公式。
- 共享字符串、富文本与受限制区域的处理需要样本验证；无法可靠保留格式的对象应报告为不支持。
- 输出核对公式、合并区域、样式及工作表数量等结构，重新解析验证文件可打开。

### 6.3 可恢复性

保存文件指纹、片段映射、翻译状态与知识快照，支持批次重试和失败恢复；重跑不得重复创建逻辑片段或混用不同版本译文。文件大小、页数、单元格数量、解析时间和压缩包解压限制需要在工程阶段定案。

## 7. 接口与回调

以下为业务方案中的接口意图，尚不是已经实现的接口；字段、状态、错误码、认证及幂等契约由后续 OpenAPI 固化。

| 方法与路径 | 用途 |
| --- | --- |
| `POST /v1/translations` | 同步短文本翻译 |
| `POST /v1/translation-jobs` | 创建长文本、批量或文件异步任务 |
| `GET /v1/translation-jobs/{jobId}` | 查询状态、进度和失败原因 |
| `GET /v1/translation-jobs/{jobId}/result` | 获取译文、报告或短期文件下载地址 |
| `POST /v1/translations/{id}/feedback` | 提交反馈 |
| `POST /v1/agent/messages` | 对话、解释与局部重译 |

文件上传、三类知识管理、审核发布、配置管理及审计查询接口在工程设计中补充。

### 7.1 回调端点清单

- 调用方只提交 `callback_endpoint_code`，或使用 `client_id` 绑定的默认端点，不接受任务请求传入任意回调 URL。
- 服务端校验端点归属调用系统；预登记系统、环境、HTTPS 地址、启停状态、有效期及允许事件。
- 管理认证配置、超时、退避策略和联系人；支持根据集成要求选择 HMAC、mTLS 或 OAuth2。
- 短文本可直接返回结果；文件使用短期签名下载地址或内部文件标识。
- 接收方用 `event_id` 去重，并关联 `job_id`；`2xx` 视为确认。网络错误和可重试响应采用指数退避，耗尽后进入失败队列并支持人工重发。
- 任务状态可查询；回调失败不改变已经完成的翻译结果。

## 8. 质量、安全与运营

- 确定性检查：术语、型号、数字、单位、受保护内容、片段 ID、占位符、空译文和重复输出。
- 语义层面：模型复核结合人工评估；不合格结果有限次数重试，仍失败转人工。
- 敏感材料遵循数据分级与私有部署约束，供应方的数据使用条款需确认。
- 文件安全扫描与隔离解析；传输/存储加密、密钥集中管理、RBAC、项目隔离及保留周期。
- 可追踪请求、模型、提示、知识版本、审核、任务和回调事件；生产日志避免直接暴露完整业务内容与凭据。
- 监控时延、用量、成本、任务失败、回调失败及审核超期。

### 8.1 验收目标

以下为原方案的建议目标，不是当前已验证结果，最终以评审及压测为准。

后续质量验收重点增加严重/实质错误片段率、漏译/增译、参数关联、必要人工修改率、审校误报/漏检和修复净收益。术语正确率不代表全文准确率；快速响应不能以跳过必要审校实现。生产组合发布要求见技术方案第 12 节和 Spec 第 11 节。

| 指标 | 建议目标与统计边界 |
| --- | --- |
| 已发布术语使用正确率 | 人工标注集上 ≥ 99% |
| 型号、数字、公式保护率 | 系统可识别对象范围内 100% |
| 典型业务人工验收通过率 | 分维保、手册、通知场景评估，≥ 90% |
| 普通文本接口可用性 | 目标 ≥ 99.9%，以最终 SLA 为准 |
| 短文本时延 | 1000 字符以内 P95 ≤ 5 秒，依模型与资源压测确定 |
| 文件任务成功率 | 范围内且未损坏的文件端到端 ≥ 98% |
| 项目/企业反馈审核 | 原则上两个工作日内完成 |

建立 500–1000 个代表性测试句段及真实结构的脱敏 Office 样本；按业务风险统计人工复核率，不单纯追求降低复核比例。
